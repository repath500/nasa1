# Gemini Decision 1
Gemini Decision 1 is a specialized multimodal model built for the
[Decisions API](/docs/decisions-api). It evaluates typed questions over text,
images, video, audio, and PDFs in a single prefill pass and returns calibrated
outcome probabilities with zero output tokens.
Use Gemini Decision 1 for request routing, policy checks across many rules at
once, candidate scoring against a rubric, tool selection, and low-latency
classification over live media streams. A single request can evaluate up to
1,000 independent questions over shared input up to 262,144 tokens:
*   **Yes/no:** Returns a calibrated probability from 0.01 to 0.99 and a
  confidence score.
*   **Single-select:** Evaluates 2 to 255 options and returns the top option,
  per-option probabilities, and confidence.
*   **Rubric rating:** Evaluates 2 to 255 ordered rubric levels and returns the
  probability-weighted expected score, per-level probabilities, and
  confidence.

## Quickstart  {% id="quickstart" %}
Evaluate a yes/no question and a routing choice over the same customer message
in one call:
{% tabs %}
  {% tab filename="decisions.py" label="Python" %}
  ```python
  from google import genai
  client = genai.Client(http_options={"api_version": "v1beta"})
  result = client.decisions.create(
      model="gemini-decision-1",
      input="The blue mug I ordered on Monday arrived cracked on Wednesday.",
      questions={
          "is_damaged": {
              "type": "noul",
              "instructions": "Did the item arrive damaged?",
          },
          "queue": {
              "type": "choice",
              "instructions": "Which support queue should handle this message?",
              "criteria": {
                  "billing": "Payment, invoice, or refund questions.",
                  "replacements": "Damaged, missing, or wrong items.",
                  "general": "Product questions and account updates.",
              },
          },
      },
  )
  damaged = result.answers["is_damaged"]
  queue = result.answers["queue"]
  print(f"P(damaged)={damaged.noul:.2f} queue={queue.choice}")
  ```
  {% /tab %}
  {% tab filename="decisions.mjs" label="JavaScript" %}
  ```javascript
  import { GoogleGenAI } from "@google/genai";
  const ai = new GoogleGenAI({ apiVersion: "v1beta" });
  const result = await ai.decisions.create({
    model: "gemini-decision-1",
    input: "The blue mug I ordered on Monday arrived cracked on Wednesday.",
    questions: {
      is_damaged: {
        type: "noul",
        instructions: "Did the item arrive damaged?",
      },
      queue: {
        type: "choice",
        instructions: "Which support queue should handle this message?",
        criteria: {
          billing: "Payment, invoice, or refund questions.",
          replacements: "Damaged, missing, or wrong items.",
          general: "Product questions and account updates.",
        },
      },
    },
  });
  const damaged = result.answers?.is_damaged;
  const queue = result.answers?.queue;
  if (damaged?.type === "noul" && queue?.type === "choice") {
    console.log(`P(damaged)=${damaged.noul} queue=${queue.choice}`);
  }
  ```
